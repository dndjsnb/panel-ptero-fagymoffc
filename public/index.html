Pertanyaan Umum

Bisa untuk bot selain Node.js?
Saat ini kami mengoptimalkan server khusus untuk environment Node.js guna memastikan performa maksimal untuk script bot WhatsApp dan Telegram. Namun, sistem Pterodactyl kami juga mendukung beberapa environment lain jika Anda memiliki permintaan khusus.
Bagaimana cara upload script bot?
Anda dapat mengunggah script melalui fitur File Manager bawaan di Panel Pterodactyl. Anda bisa mengunggah file dalam format .zip lalu mengekstraknya secara langsung di panel, atau menggunakan koneksi SFTP untuk transfer file yang lebih cepat.
Apakah Pterodactyl panel mudah digunakan?
Ya, sangat mudah! Panel Pterodactyl dirancang dengan antarmuka yang modern dan user-friendly. Anda dapat memantau log bot secara real-time, mengatur environment variables, serta melakukan start, stop, atau restart server hanya dengan satu klik.
